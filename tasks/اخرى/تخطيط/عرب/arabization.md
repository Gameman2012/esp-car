## 2) الأساس: مرحلة الأمان أولاً

```
بند #15 (enum RobotState) لازم يتنفّذ قبل أي ترجمة.
```
لأن الترجمة بدون `enum` = كسر الواجهة:

```javascript
if (statusText.includes("running"))   // ← لو الخادم بعت "يعمل" → كل الحالات تظهر Ready
```
بعد `enum` (المقترح — **غير مطبق بعد** في الكود الفعلي):
```javascript
if (data.state === "RUNNING")         // ← ثابت، مهما تغيّر النص المعروض
```
> ⚠️ الحالة الحالية: `auto.js` لا يزال يقارن `data.status` بالنصوص الإنجليزية (`"running"`, `"finished"`, `"interrupted"`) في الأسطر 272–286 و 291، ويعرض `entry.status` مباشرة في جدول التاريخ (السطر 346).
>
> **🔧 الحل المختار (الحل رقم 2):** تُترجم نصوص `.ino` إلى العربي (مثلاً `"Running"` → `"يعمل"`)، وتُعدّل مقارنات `auto.js` لتتطابق مع النصوص العربية الجديدة (مثلاً `statusText.includes("يعمل")` بدلاً من `"running"`). يُنفَّذ هذا مع تعديل الكود الفعلي، وليس فقط التوثيق.

## 4) RTL والتنسيق

| العنصر | الإجراء |
|--------|---------|
| `<html lang="ar" dir="rtl">` | في الملفين |
| `margin-left` / `margin-right` | ← استبدال بـ `margin-inline-start` / `margin-inline-end` |
| `.status-value` (`margin-left: 10px`) | ← `margin-inline-start` |
| `text-align: left/right` | ← `start` / `end` |
| `left: 0` / `right: 0` (المودال) | تحديد الاتجاهين حسب `dir` أو استخدام `inset-inline` |
| السلايدرز `input[type=range]` | ⚠️ بعض المتصفحات **تعكس** الاتجاه — أضف `direction: ltr` إن احتاج |
| الأرقام والوقت `00:00:00` | تبقى غربية (وضوح) |
| `Kp` · `Ki` · `Kd` · `PID` · `WiFi` | تبقى لاتينية (مصطلحات) |
| الأيقونات والإيموجي | تبقى كما هي |
