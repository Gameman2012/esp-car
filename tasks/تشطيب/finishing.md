## ب) التطبيق 🔌

| # | الخطوة | التفاصيل |
|---|--------|----------|
| 1 | **Compile** | Arduino IDE (ESP32 Core) — لا أخطاء تحذير/خطأ |
| 2 | **رفع الكود** | عبر USB إلى ESP32 |
| 3 | **رفع LittleFS** | Plugin: Arduino ESP32 Filesystem Uploader → `index.html` · `manual.html` · `logo.svg` · `background.svg` · `Electrolise.ttf` |
| 4 | **التشغيل** | إغلاق باب السيارة 🔌 → فتح التغذية → الضوء LED يضيء → بوق `beep()` |
| 5 | **الاتصال** | الشبكة `Sonic` (مفتوحة) → `192.168.4.1` |
| 6 | **التجربة** | الوضع التلقائي على المسار → سجل الجولات → مقارنة الأزمنة |
| 7 | **ضبط** | ضبط Kp/Ki/Kd من الواجهة → الحفظ في Preferences |
